TIPE project · Control systems and motor drive

DC motor speed control system with a supercapacitor as a power source

Description

Design and implementation of a complete speed-control system for a direct-current motor with a supercapacitor as a power source. The project covers the full control chain, from designing and simulating the power-control circuit to programming the feedback loop and processing encoder signals in real time to maintain a stable speed setpoint.

Keywords

  • Hardware design
  • Power electronics
  • Control systems
  • Embedded systems
  • PID control
  • Feedback control
  • PWM signal

Equipment and technologies

  • Microcontroller: Teensy 4.0
  • Electromechanics: DC motor, rotary encoder
  • Power electronics: Buck-Boost converters, MOSFET gate drivers
  • Programming: C++, Python
